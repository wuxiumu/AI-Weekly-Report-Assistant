## **3.**  **核心页面模块说明**







### **1）首页 Home.vue**





- 头部：首页标题+今日成长锦囊

- 显示每日/每周AI锦囊或定制建议
- 支持一键“加入成长计划”

### **api/ai.js**



```
import axios from 'axios';

export const askAI = (question, category) => {
  return axios.post('/api/ask', { question, category });
};

export const getHistory = () => {
  return axios.get('/api/history');
};

export const getGrowthCard = () => {
  return axios.get('/api/growth-card');
};
```

### **components/AiAskBox.vue**



```
<template>
  <div class="ai-ask-box">
    <el-select v-model="category" placeholder="选择主题" style="width:120px;">
      <el-option label="职业" value="career" />
      <el-option label="学业" value="study" />
      <el-option label="生活" value="life" />
      <el-option label="健康" value="health" />
    </el-select>
    <el-input v-model="question" placeholder="输入你的问题..." @keyup.enter="onAsk" style="width:320px;" />
    <el-button type="primary" :loading="loading" @click="onAsk">提问</el-button>
    <div v-if="answer" class="ai-answer">
      <b>AI答复：</b>{{ answer }}
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import { askAI } from '../api/ai'

const question = ref('')
const category = ref('career')
const loading = ref(false)
const answer = ref('')

const onAsk = async () => {
  if (!question.value.trim()) return
  loading.value = true
  answer.value = ''
  try {
    const { data } = await askAI(question.value, category.value)
    answer.value = data.answer
    // TODO: 通知父组件刷新历史
  } catch (e) {
    answer.value = '抱歉，AI服务开小差了~'
  }
  loading.value = false
}
</script>

<style scoped>
.ai-ask-box { margin: 16px 0; }
.ai-answer { margin-top: 8px; background: #f6f8fa; padding: 10px; border-radius: 4px;}
</style>
```

### **components/AiHistoryList.vue**



```
<template>
  <div class="ai-history-list">
    <div v-for="item in history" :key="item.id" class="qa-item">
      <div class="question">
        <b>Q：</b>{{ item.question }}
        <span class="time">{{ item.time }}</span>
      </div>
      <div class="answer">
        <b>A：</b>{{ item.answer }}
      </div>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { getHistory } from '../api/ai'

const history = ref([])

const fetchHistory = async () => {
  const { data } = await getHistory()
  history.value = data.list || []
}

onMounted(fetchHistory)
</script>

</style>
```
